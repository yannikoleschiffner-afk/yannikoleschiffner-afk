## Yannik Schiffner

MSc in Finance student at NUS, Singapore. BSc in Business Administration from LMU Munich.

**[Retail order execution quality at U.S. wholesalers](https://github.com/yannikoleschiffner-afk/us-equity-execution-quality)**
Bachelor thesis (grade 1.0). Using SEC Rule 605 data for 2022–23, mid-sized G1X Susquehanna gave retail orders more price improvement than market leaders Citadel and Virtu.

**[Greenwashing, ESG ratings and stock returns](https://github.com/yannikoleschiffner-afk/greenwashing-esg-stock-returns)**
NUS group project. FinBERT scoring of ~7,500 S&P 500 annual reports. ESG ratings track disclosure more than actual emissions, and greenwashing shows no reliable return penalty.

**[Insider trading detection on prediction markets](https://github.com/yannikoleschiffner-afk/prediction-market-insider-detection)**
Real-time Python system that flags likely informed trades on Polymarket from wallet behaviour, with position sizing and exit rules.

**[AI agent for a Kaggle market simulation](https://github.com/yannikoleschiffner-afk/kaggle-market-simulation-agent)**
Agent for Kaggriculture, a two-player farming and market simulation. Top 100 of 10,000+ participants.

**Tools:** Python (pandas, statsmodels, Hugging Face), R, Excel/VBA
